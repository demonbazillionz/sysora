# Sysora

**Sysora** is a modern Linux system management and monitoring application built with Python and PySide6.

It provides a graphical interface for monitoring and managing important parts of a Linux system from one place.

## Features

- System information
- CPU monitoring
- RAM monitoring
- Storage information
- Process management
- Package information
- Modern graphical interface
- Linux-focused system utilities

## Requirements

Sysora currently requires:

- Linux
- Python 3
- Git
- PySide6
- psutil

## Installation

Run this whole command in your linux terminal

```bash
git clone https://github.com/demonbazillionz/sysora.git
cd sysora
./install.sh
./run.sh
